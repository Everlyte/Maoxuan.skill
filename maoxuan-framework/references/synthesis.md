# 模型筛选与现代迁移

研究基础为 research/01—06 六份笔记。2026-09-18用户认可范围并允许连续完成后续提炼、验证和安装。

## 三重验证

| 候选 | 跨领域证据 | 能生成的新判断 | 辨识度与取舍 |
|---|---|---|---|
| 实事求是 | 社会经济调查；学习制度；具体单位的实践检验 | 先查背景，区分事实与愿望，核对经验前提，以最小有效测试修正想法 | 模型1于2026-09-23按用户要求更新；最小成本测试是现代操作化，与模型2的持续认识循环分工 |
| 知行循环 | 科学生产认识；组织试点 | 给新假设设计一次可逆验证并修正 | 保留为模型2，不夸大为现代实验科学的独创 |
| 矛盾分析——抓住当前阶段的主要矛盾 | 《矛盾论》全文中的社会历史、学习及矛盾关系分析 | 从具体过程判断主次、主要方面和转化条件，随阶段变化重选方法 | 模型3于2026-09-23完全以《矛盾论》七节正文重构；不把紧急性当主导作用，不冒充普遍科学验证 |
| 阶段与主动性 | 战争条件；认识与工作方案的阶段变化 | 判断何时继续、何时调整 | 保留为模型4；跨域支持较前3项弱，具体三阶段不迁移 |
| 集中与统筹 | 军事资源；党委多项工作 | 将有限资源用于可完成任务并维持配套 | 保留为模型5，明确组织场景是迁移而非战果证明 |
| 参与者反馈 | 组织领导；群众生活；报纸工作 | 小试点、回访受影响者、修订方案 | 保留为模型6，不能把服从当作信息质量 |

“胸中有数”“简明表达”“会前准备”“勇气”有价值，但单独的跨域与辨识度不足，不膨胀成更多心智模型。军事优势倍数、阶段日历及“三七”比例不成为固定算法。

## 不能混淆的三个层次

1. 原文主张：通过篇名、段落及版本查证，保留历史政治语境。
2. 框架转述：研究者概括作者如何分析问题，不使用原话引号。
3. 现代操作化：成本上限、预先指定反证、独立反馈和试验指标等，明确是为了让工具可运行的增补。

这是一套文本主题框架，因此采用分析者口吻；不是女娲人物模板中的沉浸式身份模拟。原文中的强断言与现代保留条件有差异时，明说差异，不伪装成作者本来已提供全部限制。
