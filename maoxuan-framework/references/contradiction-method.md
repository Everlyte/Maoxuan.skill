# 模型3：《矛盾论》的分析模型与做事方法

核心：做事情先找当前阶段的主要矛盾，研究它为什么起主导作用，再决定重点和具体方法；条件变化后重新判断，不能把一次判断永久化。

本模型的理论依据只取自这篇文章。下面的提问、比较表、反事实检查和复查信号，是为了可执行而写的现代操作步骤，不声称是原作者逐项给出的算法。原文的政治历史判断与哲学普遍性主张按其原貌解释，不因此认定所有历史因果或现代科学问题已经获证。

## 七节全文如何进入模型

| 原文部分 | 核心论点与短引 | 对做事方法的影响 |
|---|---|---|
| 一、两种宇宙观 | 从内部及相互关系研究发展；“外因是变化的条件，内因是变化的根据，外因通过内因而起作用。” | 不孤立、静止地看问题，查内部关系以及外部条件怎样发生作用；不因此否认外部伤害或凭空归责当事人。 |
| 二、矛盾的普遍性 | “矛盾存在于一切事物的发展过程中”；“每一事物的发展过程中存在着自始至终的矛盾运动。” | 从开始到结束、从平稳到变化都分析矛盾；旧过程结束后，新过程有新矛盾。不能把眼前没争吵当作没有矛盾。 |
| 三、矛盾的特殊性 | “不同质的矛盾，只有用不同质的方法才能解决。”研究对象、过程、各方面、阶段及阶段中的各方面；反对主观性、片面性、表面性。 | 不套通用答案；既看共同规律又查这次的特殊条件，不能只了解一方。根本矛盾贯穿过程，不妨碍各阶段具体矛盾及其表现变化。 |
| 四、主要的矛盾和主要的矛盾方面 | 主要矛盾的存在和发展“规定或影响着其它矛盾的存在和发展”；主要方面是矛盾中起主导作用的一方。 | 在多组矛盾中抓主导的一组；再在这一组内分析支配方面及力量变化。这两层不能混用。 |
| 五、矛盾诸方面的同一性和斗争性 | 同一性包括互为存在条件、在一定条件下互相转化；同一性有条件、相对，斗争性贯穿过程。 | 查双方怎样相互依存又相互排斥、转化需要什么条件；相对平静也可能有量的积累，不把“会变化”当必然向好。 |
| 六、对抗在矛盾中的地位 | “对抗是矛盾斗争的一种形式，而不是矛盾斗争的一切形式。” | 方法按性质选；合作中有分歧不等于必须决裂，矛盾表现形式也会变化。不把历史革命论述照搬到普通人际关系。 |
| 七、结论 | 综合普遍与特殊、主次关系、同一与斗争、不同斗争形式，反对教条主义和经验主义。 | 形成判断后仍回到具体条件，既不背概念代替调查，也不把过去经验永久化。 |

## 先把六个概念分清

- **矛盾**：在同一具体过程内，既相互联系又相互排斥的方面、倾向或关系；不是只有吵架才有矛盾，也不是逻辑上允许同一命题同时真假。
- **根本矛盾**：原文第三节所说规定整个过程本质、贯穿过程的矛盾。不自动等于每个阶段最该优先处理的一组。
- **主要矛盾**：在当前过程和阶段的多组矛盾中，起领导、决定作用，规定或影响其他矛盾的一组。
- **次要矛盾**：相对于该阶段主要矛盾而言处于次要地位，不等于不存在、不重要或可以无限忽略。
- **矛盾的主要方面**：在某一组矛盾内部处于支配地位、主要规定事物性质的方面。不是“主要矛盾”的简称，也不是自己的立场天然占优。
- **转化条件**：使双方地位、矛盾主次、表现形式或过程性质发生变化的具体条件。不能因两个概念相反，就推断可以任意互相转化。

## 可运行的方法：先找主要矛盾，再定做法

以下按依赖关系推演；无需每次把所有步骤写成报告。材料不足时回到模型1调查，而不是靠术语补齐结论。

### 1. 定对象、过程和阶段

先说清分析什么：一个团队、一项业务、一段合作还是一个学习任务？目标是什么，时间范围多长，现在处于什么阶段，判断阶段的事实是什么？同一现象在不同范围内地位可能不同，切换范围必须说明。

分清整个过程持续存在的关系与当前阶段凸显的关系；不要只按日历分阶段，要看条件、任务和关系发生了什么变化。阶段开始、相对平稳或合作存在时也有矛盾，不等到爆发再研究。

### 2. 找出具体矛盾及其联系

对有证据的每组候选，写清：**A方面与B方面，在什么条件下相互需要，又在哪里相互制约或排斥，实际表现是什么**。例如交付承诺和生产能力共同构成交付过程，但在固定周期中超额承诺与有限能力冲突；仅写“执行力差”不是完整关系分析。

查双方现状、历史变化和相互作用，不把一方的自述当全部事实。列出内部机制、外部条件及传导关系；“老板不行”“市场不好”这类单标签不能代替解释。多方关系可包含多组矛盾，不强迫所有人分成两个敌对阵营。

### 3. 比较主次，找当前主要矛盾

核心问题不是“哪件事最吵、最急、最好改”，而是：**哪一组关系目前最能规定或影响其他矛盾的发展？**

比较时检查：

- 哪些其他问题由它引出或被它持续放大？有何记录支持这条联系？
- 若它得到缓解，哪些下游问题应随之变化？若只处理其他问题，这一约束是否仍在？
- 有什么竞争解释？哪些事实会推翻现在的主次判断？

这三问是现代辅助检查，不是原文现成的评分公式。避免用一个加权分数掩盖证据不足，也不要因为某个因素可控就称它为主要矛盾。

原文第四节明确主张各阶段只有一种主要矛盾起领导作用。遵循这一分析方向，尽力找出阶段重心；但该理论主张不等于实际调查已经找到答案。证据不足就写“目前主要候选是……，需查……才能判断”，而不是列出多个“唯一主要矛盾”或凭信心选一个。若只观察到多个耦合约束，如实报告，不把未知伪装成完成。

### 4. 再看这组矛盾的主要方面

在选定的一组内部，问哪一方面当前居支配地位，靠什么资源、制度、能力或其他条件维持，对整体状态起什么作用；另一方有什么真实变化可能改变力量关系？不能把最弱的一方、最想改变的一方或最讨厌的人直接命名为主要方面。

没有足够事实判断主要方面时，明确未知，不强行为所有工程或生活问题贴标签。主要矛盾换了、同一矛盾的主要方面换了、整个过程结束了，是不同变化，应分别说明。

### 5. 找出依存关系与转化条件

不只问“怎样消除一方”，还问双方为何共处、各依赖什么，哪些条件使目前关系维持，改变什么条件才可能改变关系。合作不等于没有分歧，斗争性也不等于暴力。

检查积累与变化：表面稳定下是否存在负荷、能力、信任等变化？哪些可观察信号说明旧平衡难以维持或已进入新阶段？原文讨论量变和质变，但不能据此编造精确临界点、保证优势必定逆转或认定发展必然进步。

### 6. 根据性质选择方法，围绕主要矛盾行动

依据第三、六节，对症选择方法。现代应用中，事实认识分歧可先核验记录，能力不足可改变资源与训练，利益或规则冲突可协商安排或走正式程序；这些是应用示例，不是作者列出的现代处理表。不同性质不能一律用说服、加班、惩罚或对抗处理。

行动必须说明它改变主要矛盾的哪一方面、哪一个条件，预期如何影响整体。选最小有效检验时衔接模型1、2，另标预算、指标和停止条件为现代工具。抓重点不等于废除配套、健康、安全或他人权益；即时危险须先保护，但抢先处理的事故不自动就是长期主要矛盾。

### 7. 看结果，重新判断阶段和主次

若预期的下游变化没有出现，检查判断、方法和条件，而不是只责怪执行者。若原主要矛盾已缓和或解决，或另一组开始规定、影响其他问题，就重排重点；次要矛盾可能上升为主要矛盾。若过程已结束，重新界定新过程，不沿用旧标签。

行动后的复查信号和反证约定是现代实施设计；它们服务于原文的运动、阶段和条件分析，不证明任何哲学命题已被一次测试验证。

## 最简回答骨架

> 当前在【过程／阶段】。有依据的矛盾是【A与B、C与D】。目前主要矛盾判断为【A与B】，因为它通过【具体关系】影响【其他问题】；【证据缺口或竞争解释】仍待核实。该矛盾中【主要方面及根据／暂不能判定】。先改变【具体条件】，采用【与性质相配的方法】，同时保留【必要配套】；若出现【反证或阶段变化】，重新判断。

仅按问题需要使用，不把简单算术、情绪安慰也变成上述表格。

## 假设案例：需求堆积的交付团队

已知：过去四周每周承诺20项、完成10项；工时和缺陷率稳定，队列持续增长；会议延长主要用于协调延期。以上数字为教学假设，不是外部调研。

- 过程与阶段：现有团队、当前稳定服务范围内的交付；不扩展成公司所有经营问题。
- 候选：承诺需求与交付能力之间的矛盾；协调需求与有限工作时间之间的矛盾。
- 主次判断：目前更支持前者，因为长期流入超过流出能解释队列及延期协调增加；会议是否独立造成主要损耗仍需工时记录辨别。
- 主要方面：若进一步核实接单规则可持续强制超额承诺，且生产端无权调整范围，可判断需求承诺一方在安排机制中居支配地位；仅凭20和10两个数字不足以断言此点。
- 方法：先在获授权范围内调整承诺与范围，观察队列和等待时间；不是把需求“消灭”，也不是把开发者当作要压服的一方。具体限额先按任务差异核实。
- 转换：若队列已稳定，质量缺陷开始主导返工和交付，则重新评估质量要求与当前质量能力之间的关系，不能继续机械地把控制入口当唯一重点。

## 防止误用

不把普遍性当作编造具体矛盾的许可；不把历史政治判断当现代因果证据；不把同一性解释成双方观点都对或必须折中；不以斗争绝对性为制造冲突的理由；不将“外因通过内因”解释成受伤害都是当事人自己的错；不把“抓主要矛盾”承诺成所有问题自动解决。
